# ControlClases Recovery · COMPATIBILIDAD TEMPORAL

Este repositorio publica la página histórica de recuperación de contraseña de ControlClases mediante GitHub Pages.

## Estado

- Producción histórica: sí, mediante GitHub Pages.
- Desarrollo nuevo: no.
- Supabase dispone además de una Edge Function activa `password-recovery`.
- No eliminar ni desactivar GitHub Pages hasta verificar los redirects reales de Supabase Auth y completar una prueba de recuperación de contraseña de extremo a extremo usando únicamente la ruta definitiva.

La fuente de verdad técnica del producto ControlClases es `heyydrive/native-prototype`. Este repositorio solo se mantiene como compatibilidad temporal hasta cerrar la migración de autenticación.
